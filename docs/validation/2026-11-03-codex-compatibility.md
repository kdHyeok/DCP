## 실제 런타임

Windows의 Codex 데스크톱 런타임과 기본 모델 gpt-6.1-sol로 검사했다. 정상 설치 경로로 후보 0.2.0을 설치하고 `hooks/list`에서 네 훅을 확인했다.

업데이트 직후 기존 understanding 두 훅도 `modified`, 새 troubleshooting 두 훅은 `untrusted`였다. 명령 문자열이 같아도 내용 해시가 바뀌면 재승인이 필요하다. README와 설계 문서의 안내를 수정했고, 문자열 일치만 검사하는 테스트 이름에서도 승인 유지 보장을 제거했다.

검토한 네 훅의 현재 정의·내용 해시만 정상 설정 API로 승인했다. 기존 다른 훅 승인은 보존했으며 우회 플래그를 사용하지 않았다.
